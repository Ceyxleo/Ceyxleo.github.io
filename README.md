# ceyxleo.github.io

Personal website of Lingbo Li, Ph.D. — Earth system modeling and scientific AI.

- Plain HTML and CSS with no build step. Only `story.html` uses a small inline script for its step-by-step animation.
- Pages: `index.html` (Home), `projects.html`, `river-ai.html`, `story.html`, `publications.html`, `about.html`; shared styles in `styles.css`.
- Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

# ceyxleo.github.io

Personal website of Lingbo Li, Ph.D. — hydrology, Earth system modeling and environmental machine learning.

- Plain HTML, CSS and a few lines of JavaScript; no build step.
- Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
- Two views of the same content: `?view=research` (default) and `?view=industry`.
